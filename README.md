# Food Icon Pack — Free Classic Icons

**743+** outline food icons for recipes, menus, restaurant apps, and presentations.

## What’s in this repo

Static assets only — no app framework, no npm package.

| Folder | Contents |
|--------|----------|
| [`icons/ingredients`](icons/ingredients) | Pantry & produce (451) |
| [`icons/utensils`](icons/utensils) | Kitchen tools & glassware (121) |
| [`icons/dishes`](icons/dishes) | Popular meals (74) |
| [`icons/beverages`](icons/beverages) | Drinks, coffee, cocktails (97) |

Each pack has:

- `svg/*.svg`
- `png_small/` — 64px
- `png_medium/` — 256px
- `png_big/` — 512px

[`icons/meta.json`](icons/meta.json) lists sync time and counts.
